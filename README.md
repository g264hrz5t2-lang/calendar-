# 都内ミニシアター 上映スケジュール

theaters.json に並べた劇場の上映スケジュールを映画.comから毎朝取得し、1枚のHTMLに書き出します。現在13館。

## 使い方

```bash
npm install
npm run build      # dist/index.html と dist/data.json を生成
npm run inspect    # 取得した生データを表示（パーサ調整用）
```

## 構成

| ファイル | 役割 |
|---|---|
| `theaters.json` | 対象館の設定。館を増やすならここに1行足すだけ |
| `build.mjs` | 取得・解析・検証・生成 |
| `template.html` | 表示側。`/*__DATA__*/` にデータが差し込まれる |
| `.github/workflows/build.yml` | 毎朝6時（JST）に実行し GitHub Pages に配信 |

館を追加するときは、映画.comの劇場ページURL（`/theater/13/{エリアID}/{劇場ID}/`）を
`theaters.json` に足してください。他のファイルは触らなくて構いません。

## 設計上、必ず理解しておくべきこと

**映画.comは高頻度で古いキャッシュを返します。** 開発中の実測で、12館中4館が
1〜2ヶ月前のページを返しました。同じURLを再取得すると正しいページが返ります。

そのため `build.mjs` は、取得したページの先頭日付が実行日と一致するかを毎回検証し、
違えば最大4回まで再取得します。それでも駄目な館は**データを捏造せず欠落させ**、
ログに `△ 取得できなかった館` として出します。この検証を外さないでください。
外すと、気づかないまま2ヶ月前の時刻表を毎朝眺めることになります。

**日付は必ず日本時間で判定しています。** GitHub Actions はUTCで動くため、
`new Date()` をそのまま使うと日付が1日ずれます。`todayJST()` を経由してください。

**パーサはクラス名に依存していません。** 日付ラベル・時刻・見出しを文書順の
トークン列として読み、直前の見出しと直前の日付に時刻を割り当てる方式です。
映画.com側のCSSが変わっても、表示されるテキストの形（`8/9（日）`、`10:30～13:20`）が
変わらない限り動きます。逆にその形が変わったら `pushToken()` の正規表現を直します。

**終了時刻の扱い。** 映画.comが終了時刻を書いている回は `x:1`、書いていない回は
上映時間から加算した推定値で `x:0` としています。画面では実線と破線で区別されます。
一律に推定で埋めないのは、ズレたときに気づけるようにするためです。

## 注意

個人利用の範囲を想定しています。取得間隔は館ごとに1.2秒空けています。
公開・再配布する場合は映画.comの利用規約を確認してください。
